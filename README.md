# glwin5 — ไฟล์ติดตั้ง

ที่เก็บนี้มีเฉพาะไฟล์ติดตั้ง (Releases) ของโปรแกรมบัญชี glwin5 สำหรับการอัปเดตอัตโนมัติ — ไม่มีซอร์สโค้ด

This repository only hosts glwin5 installers for the in-app auto-updater. It contains no source code.

ดาวน์โหลด: เลือกไฟล์ `glwin5-setup-<version>.exe` จาก [Releases](../../releases/latest)
